Install UniDesk

UniDesk is free and open source, but it isn’t code-signed, so your computer’s safety check may stop it the first time. Follow the steps for your system: turn the check off, confirm it’s off, then install.

  1. Turn off Smart App Control

    Windows 11 may have Smart App Control on. It blocks apps that aren’t code-signed and has no “run anyway” option.

    • Open Start, type Windows Security and open it.
    • Go to App & browser control → Smart App Control settings.
    • Choose Off.

    Windows 10 doesn’t have Smart App Control: skip to step 3. On some Windows 11 versions, Smart App Control can’t be switched back on later without reinstalling Windows.

  2. Check that it’s off

    Open Start, type PowerShell, open it, paste this and press Enter:

    $s=$null; try { $s=(Get-MpComputerStatus -ErrorAction Stop).SmartAppControlState } catch {}; if (-not $s) { $v=(Get-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\CI\Policy' -ErrorAction SilentlyContinue).VerifiedAndReputablePolicyState; if ($v -eq 1) { $s='On' } elseif ($v -eq 2) { $s='Evaluation' } else { $s='Off' } }; if ($s -eq 'Off') { 'OK: Smart App Control is off. You can install UniDesk.' } else { "NOT YET: Smart App Control is $s. Turn it off, then run this check again." }

    It should say OK: Smart App Control is off. If it says NOT YET, go back to step 1.

  3. Download and run the installer

    Download installerPortable .zip

    If you see “Windows protected your PC” (SmartScreen), click More info → Run anyway. Then click Yes when Windows asks for administrator permission: UniDesk runs as administrator so you can control every app, the lock screen and UAC prompts.

  1. Download UniDesk

    Pick the one for your Mac (Apple menu → About This Mac → “Chip”):

    Apple Silicon (M1–M4)Intel

    Open the .dmg and drag UniDesk into Applications.

  2. Let macOS open it (Gatekeeper)

    macOS stops apps from developers it hasn’t verified. Allow UniDesk once:

    • Open UniDesk from Applications. macOS says it can’t be opened: click Done.
    • Open System Settings → Privacy & Security, scroll down and click Open Anyway next to UniDesk, then enter your password.

    Or do it in one step: open Terminal, paste this and press Return:

    xattr -dr com.apple.quarantine /Applications/UniDesk.app

  3. Check that it’s allowed

    In Terminal, paste this and press Return:

    xattr -p com.apple.quarantine /Applications/UniDesk.app >/dev/null 2>&1 && echo "NOT YET: macOS will still ask. Use Open Anyway (step 2)." || echo "OK: UniDesk is allowed to open."

    After using Open Anyway the check may still say NOT YET; that’s fine as long as UniDesk now opens.

  4. Allow screen and control

    So people you invite can see and control your Mac, turn on UniDesk in System Settings → Privacy & Security → Screen Recording and Accessibility. UniDesk opens these for you the first time.

  1. Download UniDesk

    Download AppImage

  2. Allow it to run

    Linux doesn’t run downloaded files until you mark them as programs. In a terminal, in the folder you downloaded to:

    chmod +x UniDesk-1.1.0-linux-x64.AppImage

    AppImages need FUSE 2. On Ubuntu 24.04 and newer: sudo apt install libfuse2t64. On Ubuntu 22.04: sudo apt install libfuse2.

  3. Check everything is ready

    [ -x UniDesk-1.1.0-linux-x64.AppImage ] && echo "OK: the file can run" || echo "NOT YET: run the chmod command"; (ldconfig -p | grep -q "libfuse.so.2") && echo "OK: FUSE 2 is installed" || echo "NOT YET: install libfuse2 (see above)"; [ "$XDG_SESSION_TYPE" = "wayland" ] && echo "NOTE: you're on Wayland. Remote control works on X11: choose 'Ubuntu on Xorg' at the login screen." || echo "OK: X11 session"

  4. Run UniDesk

    ./UniDesk-1.1.0-linux-x64.AppImage

    No FUSE? It also runs with ./UniDesk-1.1.0-linux-x64.AppImage --appimage-extract-and-run.
